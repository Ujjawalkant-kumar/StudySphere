# StudySphere — Student Productivity Dashboard

StudySphere is a responsive, frontend-only study planner that helps students organize study tasks and track progress.

## Features
- Add study tasks with a subject and planned duration
- Mark tasks as completed or pending
- Filter by all, pending, and completed
- Delete tasks or clear completed tasks
- Dashboard statistics for tasks, planned focus time, and completion percentage
- Subject-wise progress overview
- Saves tasks in browser LocalStorage
- Responsive layout for desktop, tablet, and mobile

## Built With
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Run Locally
1. Download or clone this repository.
2. Open `index.html` in a browser.

No installation or build tools are required.

## Project Structure
```text
StudySphere/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Deploy with GitHub Pages
1. Push the files to a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Wait for deployment; GitHub will display the published URL in Pages settings.

## Note
This is a frontend demonstration project. Data is stored in the current browser using LocalStorage. It has no backend, cloud synchronization, or multi-user authentication.
